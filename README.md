# 我的工作台 · Daily Workstation

一个纯前端的个人每日工作台 Web App，支持学习打卡、运动锻炼、护肤流程、日常记账四个模块。数据保存在浏览器 localStorage，刷新不丢失。

## 功能模块

| 模块 | 功能 |
|---|---|
| **首页** | 今日完成进度环、连续打卡天数、4 个模块快捷入口、本周运动/支出小图 |
| **学习打卡** | 每日任务勾选、自定义任务、连续打卡天数、学习时长记录、近 30 天趋势图 |
| **运动锻炼** | 运动类型可自由增删改（含卡路里系数）、时长/卡路里记录、累计统计、本周柱状图 |
| **护肤** | 晨间/晚间步骤可自由增删改、护肤品余量管理、本周完成率圆环图 |
| **记账** | 收入/支出快速记账、多分类、本月收支统计、支出分类饼图、流水明细 |

## 补记与自定义

- **日期可选**：四个模块顶部都有日期条，点左右箭头或点中间日期即可补记昨天/更早的记录（不能选未来），随时可点「回到今天」。
- **运动类型自定义**：运动页右上角「类型」按钮，可改名称、改每分钟消耗，可新增（如爬山）、删除；删除不影响历史记录。
- **护肤步骤自定义**：护肤页右上角「步骤」按钮，晨间/晚间步骤可改名、增删；改名自动同步历史打卡。

## 使用方式

1. 直接用浏览器打开 `index.html` 即可使用。
2. 所有数据自动保存在浏览器本地，换浏览器/清缓存会丢失。
3. 推荐在手机上用浏览器打开，可添加到主屏幕当作 App 使用。

## 技术说明

- 纯 HTML/CSS/JavaScript，无后端依赖。
- 使用 [Chart.js](https://www.chartjs.org/) 绘制图表（已内联进单文件）。
- 图标使用内联 SVG，不依赖系统 emoji 字体。
- 改代码后运行 `python3 build.py` 重新生成单文件 `index.html`。

## 提示

- 首次打开会自动写入默认任务、运动类型和护肤步骤模板。
- 老版本数据会自动升级，打卡记录不丢失。
- 如需清空数据，可在浏览器控制台执行 `localStorage.clear()` 后刷新页面。
